# Логотипы партнёров

Сюда кладутся логотипы обменников. Имя файла указывается в поле `logo` в [`../../data/partners.js`](../../data/partners.js).

| UNIOCHANGE                | `uniochange.png`    | спарсен с сайта                     |

| ATPayz                    | `atpayz.webp`       | спарсен с сайта                     |
| BITKIT.MONEY              | `bitkit.svg`        | спарсен с сайта                     |

## Требования

- Ширина ~240px (логотип на карточке отображается в квадрате 56×56 на белой подложке).
- Прозрачный фон для PNG/SVG приветствуется.
- Расширение может быть `.png`, `.svg` или `.webp` — главное, чтобы оно совпадало с полем `logo` в `partners.js`.

## Фолбэк

Если файла нет или он не загрузился, карточка автоматически покажет плитку с инициалами названия на цветном фоне — сайт не сломается.
