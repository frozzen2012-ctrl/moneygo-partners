# MoneyGo Partners

Независимый партнёрский каталог проверенных обменников, помогающих **купить и продать цифровую валюту MoneyGo** за криптовалюту.

Статический сайт без фреймворков и сборщиков — открывается простым открытием `index.html`. Двуязычный (RU/EN), тёмная тема, адаптив.

**Прод:** https://money-go-partners.com/ (раздаётся через GitHub Pages, кастомный домен)

---

## Структура

```
index.html          — разметка лендинга (одна страница с якорями)
css/styles.css       — все стили (тёмная тема, адаптив)
js/main.js           — i18n, рендер партнёров, поиск/фильтр, форма, анимации
data/partners.js     — СПИСОК ПАРТНЁРОВ (правьте этот файл, чтобы обновить каталог)
data/i18n.js         — все тексты RU + EN
assets/favicon.svg   — иконка
assets/og-image.svg  — превью для соцсетей (Open Graph)
assets/logos/        — логотипы партнёров (+ инструкция в README внутри)
.nojekyll            — отключает обработку Jekyll на GitHub Pages
```

## Как обновить список партнёров

Откройте [`data/partners.js`](data/partners.js) и отредактируйте массив `window.PARTNERS`. Каждый партнёр:

```js
{
  name: "MINE.exchange",          // название (не переводится)
  logo: "assets/logos/mine.png",  // путь к логотипу; пусто => плитка с инициалами
  url: "https://mine.exchange/",  // ссылка на сайт партнёра (открывается в новой вкладке)
  badges: ["AUTO"],               // бейджи
  status: "active",               // "active" | "potential"
  currencies: ["BTC", "USDT"]     // опционально
}
```

Если у партнёра нет файла логотипа или он не загрузился — карточка автоматически показывает плитку с инициалами. Куда класть файлы — см. [`assets/logos/README.md`](assets/logos/README.md).

## Как изменить тексты / переводы

Все строки интерфейса — в [`data/i18n.js`](data/i18n.js), объект `window.I18N` с ключами `ru` и `en`. В разметке тексты подставляются по атрибуту `data-i18n="<ключ>"`. Язык по умолчанию — RU, выбор сохраняется в `localStorage`.

## Форма «Стать партнёром»

Форма отправляет заявки на **ps@in1go.cc**. Сейчас в `index.html` стоит плейсхолдер endpoint `<FORMSPREE_ENDPOINT>` — пока он не заменён, форма работает через `mailto:` фолбэк.

Чтобы включить отправку без открытия почтового клиента:

1. Зарегистрируйте форму на [formspree.io](https://formspree.io/) с получателем **ps@in1go.cc**.
2. Скопируйте endpoint вида `https://formspree.io/f/xxxxxxxx`.
3. Вставьте его в атрибут `action` у `<form id="partner-form">` в `index.html` вместо `<FORMSPREE_ENDPOINT>`.

JS сам определит рабочий endpoint и переключится с `mailto` на fetch-отправку.

## Локальный запуск

Просто откройте `index.html` в браузере. Для корректной работы относительных путей можно поднять простой сервер:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Деплой (GitHub Pages)

Сайт раздаётся из ветки `main`, корень `/`. После пуша включите Pages в **Settings → Pages → Source: Deploy from a branch → main / (root)**. Файл `.nojekyll` уже в корне.
